# Design Philosophy

SnapMoment bukan sekadar website photobooth.

Website harus memberikan pengalaman yang menyenangkan, ringan, dan memorable, seperti menggunakan mesin photobooth Korea modern.

Semua keputusan desain harus mengutamakan:

- Simplicity
- Consistency
- Playfulness
- Performance
- Accessibility

UI harus terlihat premium namun tetap mudah digunakan oleh semua orang.

# Design Principles

## 1. Cute First

Setiap komponen harus terlihat ramah.

Hindari bentuk tajam.

---

## 2. Keep It Clean

Jangan memenuhi layar dengan dekorasi.

Dekorasi hanya sebagai aksen.

---

## 3. Focus on Photos

Foto adalah konten utama.

UI tidak boleh lebih mencolok daripada hasil foto.

---

## 4. Consistency

Semua komponen harus memiliki gaya visual yang sama.

---

## 5. Motion with Purpose

Animasi digunakan untuk memberi feedback.

Bukan sekadar hiasan.
